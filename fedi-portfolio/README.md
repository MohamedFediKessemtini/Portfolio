# Fedi Kessemtini — Mechanical Engineering Portfolio

Site portfolio statique (HTML, CSS, JavaScript) : conception mécanique, CAO, simulation par éléments finis et projets d'ingénierie.

## Structure

```
.
├── index.html   # Contenu de la page
├── styles.css   # Styles
├── script.js    # Menu mobile
└── README.md
```

## Lancer en local

Ouvrir `index.html` dans le navigateur, ou utiliser l'extension VS Code **Live Server** (clic droit sur `index.html` > *Open with Live Server*).

## Publication

Le site est publié avec GitHub Pages (Settings > Pages > Deploy from a branch > `main` / `/root`).
